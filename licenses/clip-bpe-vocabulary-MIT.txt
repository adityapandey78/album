Describe-it search tokenizer: the CLIP byte-pair vocabulary, by OpenAI (https://github.com/openai/CLIP)

app/src/main/assets/describe/bpe_merges.txt holds the first 48,894 merges of bpe_simple_vocab_16e6.txt.gz (sha256
924691ac288e54409236115652ad4aa250f48203de50a9e4722a6ecd48d6804a), the merges CLIP's tokenizer uses, one per line, with
the file's version line left out. Album takes the file from Meta's perception_models repository (commit
3e352cca660658d4b5c90f42a7808b11469e4c66, core/vision_encoder/), where it is byte for byte the one in OpenAI's CLIP
repository; Perception Encoder's text encoder was trained with this tokenizer. Only the vocabulary is used, none of
OpenAI's models.
