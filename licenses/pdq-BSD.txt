Photo hashing: PDQ (Meta, https://github.com/facebook/ThreatExchange/tree/main/pdq)

app/src/main/java/com/aditya/album/Pdq.kt is a Kotlin port of PDQ's Java reference implementation
(pdq/java/src/main/java/pdqhashing: hasher/PDQHasher.java, types/Hash256.java, utils/MatrixUtil.java), made for Album
from the repository's main branch in October 2026. Changes: Kotlin instead of Java; flat arrays instead of nested ones;
the eight dihedral hashes in one call; no file reading (Album decodes the photo itself). It gives the same hashes as the
reference for the same pixels (app/src/test/java/com/aditya/album/PdqTest.kt). Torben's median (MatrixUtil.torben) is
public domain: algorithm by Torben Mogensen, implementation by N. Devillard.

The test photo app/src/test/resources/cleanup/bridge-1-original.jpg comes from the same repository (pdq/data).
